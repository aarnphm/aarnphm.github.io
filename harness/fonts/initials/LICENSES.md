# Drop-cap faces: origin and licence

Gate: only faces whose rights holder explicitly allows free use and redistribution of modified
files (OFL, public domain, or a first-person grant) ship. Everything below was read from the
font files' own name tables (fontTools, nameIDs 0/5/9/10/13/14) and from the sources linked;
gwern.net's descriptions were used only as leads.

## What the build does to the files

`initials.py` subsets each original to one letter per woff2 (hinting, GSUB/GPOS, gasp, FFTM
dropped; name records 0–6, 9, 10, 13, 14 kept, so the copyright and designer strings travel with
every file) and normalises the vertical metrics (ascent = UPM, descent = 0, USE_TYPO_METRICS) so
the CSS sizing is the same on every platform. No outline is changed. The merged TTFs in
`harness/fonts/initials/` were produced with `fontTools.merge` from gwern.net's 26 one-letter
files per face; their name tables are the originals'.
