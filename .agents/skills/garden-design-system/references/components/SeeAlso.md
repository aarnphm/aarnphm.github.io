# SeeAlso

The see-also tree at the end of a note: related notes drawn as a small outline with tree lines.

**Source:** `quartz/components/SeeAlso.tsx` · styles: `quartz/components/styles/seealsoTree.scss`

## Preview

A copy of the server-rendered markup from `/thoughts/Attention` (selector `section.seealso-tree`), styled by `site/garden.css`, the site's compiled CSS pruned to the rules these previews use. Links point to `#` and lists keep their first 8 items. The component has no script; the markup is the whole component.

## Rules

- Tree lines are decorative and `aria-hidden`; each label is a link.
