# Table

A Markdown table inside its scroll container.

**Source:** `quartz/plugins/transformers/ofm.ts` · styles: `quartz/styles/base.scss`

## Preview

A copy of the server-rendered markup from `/stream/on/2026/08/22` (selector `.table-container`), styled by `site/garden.css`, the site's compiled CSS pruned to the rules these previews use. Links point to `#` and lists keep their first 8 items. The component has no script; the markup is the whole component.

## Rules

- The container scrolls sideways when the table is wider than the column.
- Write absolute values as `\lvert x \rvert`; a literal `|` splits the cell.
