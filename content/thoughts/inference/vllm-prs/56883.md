## Purpose

Add per-folder agent instructions (`AGENTS.md`, with `CLAUDE.md` importing it) for the three model-output parsing packages:

- `vllm/parser/` — the unified `Parser` and the declarative parser engine
- `vllm/tool_parsers/` — legacy `ToolParser` interface, registration table, adapters
- `vllm/reasoning/` — legacy `ReasoningParser` interface and its structured-output consumer

These are domain guides in the sense of `docs/contributing/editing-agent-instructions.md`: each records what an agent cannot infer from the code alone. Each file is well under the 300-line domain-guide budget and every referenced file/symbol was checked against current `main`.
