## Purpose

Current codes only support prefill and decode with same KV cache layout.
In this PR, would like to enable for new option that when prefill is HND, and receiver is HND.
In that case, nixl*read can still copy data in big chunk (num_kv_head * tp*ratio * block_size \* head_size), and meanwhile, decode attn is not limited to HND only attention.

## Test Plan

Tested with vllm/tests/v1/kv_connector/nixl_integration/run_accuracy_test.sh

prefill:

```
    BASE_CMD="CUDA_VISIBLE_DEVICES=3" \
    UCX_NET_DEVICES=all \
    VLLM_NIXL_SIDE_CHANNEL_PORT=$SIDE_CHANNEL_PORT \
    vllm serve $model_name \
    --port $PORT \
    --enforce-eager \
    --block-size 128 \
    --gpu-memory-utilization 0.2 \
    --tensor-parallel-size 1 \
    --kv-transfer-config '{"kv_connector":"NixlConnector","kv_role":"kv_both"}'"
```

decode:

```
BASE_CMD="CUDA_VISIBLE_DEVICES=4, 5" \
    UCX_NET_DEVICES=all \
    VLLM_KV_CACHE_LAYOUT=NHD \
    VLLM_NIXL_SIDE_CHANNEL_PORT=$SIDE_CHANNEL_PORT \
    vllm serve $model_name \
    --port $PORT \
    --enforce-eager \
    --block-size 128 \
    --gpu-memory-utilization 0.2 \
    --tensor-parallel-size 2 \
    --kv-transfer-config '{"kv_connector":"NixlConnector","kv_role":"kv_both"}'"
```
