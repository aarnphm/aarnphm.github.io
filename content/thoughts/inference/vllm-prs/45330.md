### Describe the bug

\_validate_remote_agent_handshake in NixlConnectorWorker (worker.py:~1498) asserts:

python
assert remote_block_len == (self.block_len_per_layer[0] \* tp_ratio) // block_size_ratio

This assumes block_len scales linearly with 1/tp_size. However, when tp_size > num_kv_heads, GQA replication caps num_kv_heads_per_rank at 1, so block_len stops scaling. Both sides end up with the same block_len despite different TP sizes, causing the assertion to fail.

### Steps to reproduce

Run disaggregated inference with:

- Model: Any model with few KV heads (e.g., meta-llama/Llama-3.2-1B-Instruct — 8 KV heads)
- Prefill: --tensor-parallel-size 8
- Decode: --tensor-parallel-size 16
- KV connector: NixlConnector

### Error

AssertionError: Remote P worker KV layer cache must be of shape [2, N, local_kv_heads*tp_ratio, page_size, head_dim] and same dtype.

### Configurations tested (model with 8 KV heads)

| Config   | D_TP > kv_heads? | P_TP > kv_heads? | Result |
| -------- | ---------------- | ---------------- | ------ |
| tp2→tp4  | No               | No               | PASS   |
| tp4→tp8  | No (edge: 8=8)   | No               | PASS   |
| tp8→tp16 | Yes (16>8)       | No (edge)        | FAIL   |
| tp4→tp16 | Yes (16>8)       | No               | FAIL   |
| tp16→tp8 | No (edge)        | Yes (16>8)       | FAIL   |

### Root cause

When tp > num_kv_heads, num_kv_heads_per_rank = max(1, num_kv_heads // tp) = 1 (GQA replication). Block_len is proportional to num_kv_heads_per_rank, so it caps at
a single head's worth. The assertion expects remote_block_len = local_block_len × tp_ratio but both sides report the same block_len due to this cap.

### Suggested fix

The validation should account for GQA replication. For example, skip the strict proportionality check when max(local_tp, remote_tp) > total_num_kv_heads:

```
if tp_ratio > 0:
    expected = (self.block_len_per_layer[0] * tp_ratio) // block_size_ratio
    if remote_block_len != expected:
        # Allow when GQA replication caps block_len on either side
        total_kv_heads = self.transfer_topo.total_num_kv_heads
        if max(self.transfer_topo.tp_size, remote_tp_size) > total_kv_heads:
            pass  # block_len doesn't scale beyond kv_head count
        else:
            assert False, (
                "Remote P worker KV layer cache must be of shape [2, N,"
                " local_kv_heads*tp_ratio, page_size, head_dim] and same dtype."
            )

```
