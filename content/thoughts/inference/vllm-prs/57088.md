# #57088 [Docs] Add ecosystem kernels index skill

## Purpose

This PR adds a new skill: `kernels-ecosystem`. It is a one-off snapshot of all kernels GPT-6 could find in vLLM, SGLang, TRTLLM, TokenSpeed, and FlashInfer. It is grouped by operator at the top-level for easy browsing. The skill includes a workflow to update the index, which we will need to do periodically. Ideally this index can be hosted outside of vLLM and serve a more frequently crawled index, but for now I think there is a lot of value in merging this skill.

Already, I have discovered a dozen new kernels that I hadn't previously known about.
