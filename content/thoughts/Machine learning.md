Machine learning fits models to data so they can make predictions or choose actions on new inputs.

In the usual taxonomy, $\mathrm{DL} \subset \mathrm{ML} \subset \mathrm{AI}$: [[thoughts/deep learning|deep learning]] is part of machine learning, which is part of artificial intelligence. See [Deep Learning, chapter 1](https://www.deeplearningbook.org/contents/intro.html).

[[thoughts/AGI|AGI]] concerns the breadth of tasks a system can perform. It describes a capability goal; machine learning describes an approach to building systems. See [Levels of AGI](https://arxiv.org/abs/2311.02462).
