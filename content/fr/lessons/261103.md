## les articles partitifs et les quantités

Pour présenter une quantité indéterminée, on utilise **du / de la / de l'**, ou **des** au pluriel dans ces exemples.

| forme | usage                           | exemple                               |
| ----- | ------------------------------- | ------------------------------------- |
| du    | masculin singulier              | {{`du fromage`}}, {{`du lait`}}       |
| de la | féminin singulier               | {{`de la crème`}}, {{`de la farine`}} |
| de l' | devant une voyelle ou un h muet | {{`de l'eau`}}, {{`de l'huile`}}      |
| des   | pluriel                         | {{`des frites`}}, {{`des nouilles`}}  |

Avec une mesure, on emploie **mesure + de / d' + aliment**. Avec un nombre d'éléments, on compte directement : **un œuf**, **deux œufs**.

| quantité précise   | phrase à retenir                          |
| ------------------ | ----------------------------------------- |
| lait               | {{`une tasse de lait`}}                   |
| bouillon de poulet | {{`quatre tasses de bouillon de poulet`}} |
| chocolat           | {{`une petite tablette de chocolat`}}     |
| sel et poivre      | {{`une pincée de sel et de poivre`}}      |
| œuf                | {{`un œuf`}}                              |

**Du lait** décrit une quantité indéterminée ; **une tasse de lait** donne la mesure. Dans ces recettes, après **une tasse**, on utilise **de lait**.

### aimer : un nom ou un infinitif

- **Aimer + le / la / l' / les + nom**, pour un gout général : {{`J'aime le fromage.`}} / {{`J'aime les frites.`}}
- **Aimer + infinitif**, pour une activité : {{`J'aime danser.`}} / {{`J'aime cuisiner.`}}
- {{`J'aime beaucoup la danse.`}} parle de la danse ; {{`J'aime beaucoup danser.`}} parle de l'activité de danser.
- {{`J'ai le bec sucré.`}} = I have a sweet tooth. **Les sucreries** = sweets.

### aimer, manger et la négation

| phrase                            | ce qu'elle exprime                                         |
| --------------------------------- | ---------------------------------------------------------- |
| {{`Je mange du fromage.`}}        | une quantité indéterminée                                  |
| {{`Je ne mange pas de fromage.`}} | la négation du partitif, avec **de**                       |
| {{`J'aime le fromage.`}}          | un gout général, avec l'article défini **le**              |
| {{`Je n'aime pas le fromage.`}}   | le défini **le** reste après **aimer**, même à la négation |

Avec **manger / boire**, les partitifs deviennent généralement **de / d'** dans une négation avec **ne … pas**. Pour un gout général avec **aimer**, on garde **le / la / l' / les** : {{`Je n'aime pas les sucreries.`}}

la randonnée / marcher dans la forêt.

### les nuances à connaitre

Les exemples suivants sont indépendants et adaptables. **J'aime bien** est positif ; **j'adore** exprime un gout très fort.

| formule                | exemple supplémentaire                       |
| ---------------------- | -------------------------------------------- |
| j'aime un peu          | {{`J'aime un peu les pommes.`}}              |
| j'aime bien            | {{`J'aime bien le chocolat.`}}               |
| j'aime beaucoup        | {{`J'aime beaucoup le riz.`}}                |
| je n'aime pas trop     | {{`Je n'aime pas trop le thé.`}}             |
| je n'aime pas vraiment | {{`Je n'aime pas vraiment cuisiner.`}}       |
| je n'aime pas beaucoup | {{`Je n'aime pas beaucoup le brocoli.`}}     |
| je n'aime pas du tout  | {{`Je n'aime pas du tout les champignons.`}} |

**Je déteste** et **j'ai horreur de** expriment un rejet fort : {{`Je déteste danser.`}} / {{`J'ai horreur du fromage.`}} / {{`J'ai horreur de cuisiner.`}} Dans **avoir horreur du fromage**, **du = de + le**, une contraction liée à **horreur de**.

Placement : {{`J'aime beaucoup le riz.`}} / {{`Je n'aime pas du tout le riz.`}} Avec **aimer**, l'article défini reste présent dans toutes ces variantes.

## exprimer une préférence, p. 113

**Préférer** indique ce qu'on choisit entre plusieurs possibilités. Au présent : **je préfère, tu préfères, il / elle / on préfère, nous préférons, vous préférez, ils / elles préfèrent**.

- **Aimer X, mais préférer Y** : {{`J'aime le fromage, mais je préfère le riz.`}}
- **Deux activités à l'infinitif** : {{`J'aime danser, mais je préfère cuisiner.`}}
- **Préférer A à B**, avec des noms : {{`Je préfère le riz aux pâtes.`}} Ici, **aux = à + les**. Avec un nom masculin singulier : {{`Je préfère le thé au café.`}}, **au = à + le**.

**Préféré / préférée** s'accorde avec le nom : **mon plat préféré**, **ma boisson préférée**.

| question                               | réponse modèle                            |
| -------------------------------------- | ----------------------------------------- |
| {{`Quel est ton plat préféré ?`}}      | {{`Mon plat préféré, c'est la poutine.`}} |
| {{`Quelle est ta boisson préférée ?`}} | {{`Ma boisson préférée, c'est l'eau.`}}   |
| {{`Qu'est-ce que tu préfères ?`}}      | {{`Je préfère le riz.`}}                  |
| {{`Est-ce que tu aimes le riz ?`}}     | {{`Oui, j'aime beaucoup le riz.`}}        |

Les deux premières questions demandent un favori ; la troisième est ouverte ; la dernière peut recevoir **oui** ou **non**. Voir [[fr/episode-15#exprimer-ses-préférences-p-113|les autres exemples de l'épisode 15]].
