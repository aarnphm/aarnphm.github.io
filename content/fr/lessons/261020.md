### construire une description

1. **Le vêtement** : {{`Elle porte une robe.`}}
2. **La couleur** : {{`Elle porte une robe bleu foncé.`}}
3. **La coupe ou les manches** : {{`Elle porte une robe bleu foncé sans manches.`}}
4. **Les accessoires** : {{`Elle tient un petit sac à main.`}}

**Porter au présent** : **je porte, tu portes, il / elle porte, nous portons, vous portez, ils / elles portent**. Exemple au pluriel : {{`Elles portent des bottes.`}}

On utilise **tenir** pour préciser qu'un objet est dans la main : {{`Elle tient un parapluie.`}} Le verbe **tenir** devient **tient** avec **il / elle**.

### les couleurs et l'accord

Une couleur simple s'accorde généralement avec le nom : **un t-shirt blanc**, **une chemise blanche** ; **un pantalon noir**, **des bottes noires** ; **une robe rouge**, **des robes rouges** ; **un imperméable brun**, **des bottes brunes**.

**Orange** reste invariable : {{`Elle porte des bottes orange.`}} Les couleurs composées restent aussi invariables : **une robe bleu foncé**, **des vestons bleu marine**, **des chemises bleu clair**, **des hauts bleu-violet**.

Pour la couleur d'un vêtement, on peut demander : {{`De quelle couleur est sa chemise ?`}} → {{`Sa chemise est bleu clair.`}}

## station 7 : les directives, révision du jour

Notes de la capture du **20 octobre 2026**, « Les directives / Préparez-vous ». **Piste 1 : pouvoir ; piste 2 : devoir ; piste 3 : exercice d'association ; piste 4 : nous et on à l'oral.** Les tableaux et les exemples imprimés sont visibles. Les enregistrements ne sont pas fournis ici ; les autres phrases ci-dessous sont des **exemples de révision**.

### pouvoir au présent, piste 1

**Pouvoir** = **can / may** : exprimer une possibilité, une capacité ou une permission selon le contexte.

| sujet          | forme positive            | forme négative                   |
| -------------- | ------------------------- | -------------------------------- |
| je             | {{`je peux`}}             | {{`je ne peux pas`}}             |
| tu             | {{`tu peux`}}             | {{`tu ne peux pas`}}             |
| il / elle / on | {{`il / elle / on peut`}} | {{`il / elle / on ne peut pas`}} |
| nous           | {{`nous pouvons`}}        | {{`nous ne pouvons pas`}}        |
| vous           | {{`vous pouvez`}}         | {{`vous ne pouvez pas`}}         |
| ils / elles    | {{`ils / elles peuvent`}} | {{`ils / elles ne peuvent pas`}} |

Exemples : {{`Je peux nager.`}} = I can swim. {{`Tu peux entrer.`}} = You may come in. {{`Nous ne pouvons pas fumer ici.`}} = We cannot smoke here, par exemple parce que c'est interdit.

### devoir au présent, piste 2

Dans cette station, **devoir** = **must / have to** : exprimer une obligation ou donner une directive.

| sujet          | forme positive            | forme négative                   |
| -------------- | ------------------------- | -------------------------------- |
| je             | {{`je dois`}}             | {{`je ne dois pas`}}             |
| tu             | {{`tu dois`}}             | {{`tu ne dois pas`}}             |
| il / elle / on | {{`il / elle / on doit`}} | {{`il / elle / on ne doit pas`}} |
| nous           | {{`nous devons`}}         | {{`nous ne devons pas`}}         |
| vous           | {{`vous devez`}}          | {{`vous ne devez pas`}}          |
| ils / elles    | {{`ils / elles doivent`}} | {{`ils / elles ne doivent pas`}} |

Exemples : {{`Je dois étudier.`}} = I have to study. {{`Vous devez écouter.`}} = You must listen. Pour une interdiction : {{`Tu ne dois pas fumer.`}} = You must not smoke.

### construire les phrases

**Sujet + pouvoir / devoir conjugué + infinitif** : {{`Tu peux partir.`}} / {{`Nous devons écouter.`}} Le deuxième verbe reste à l'infinitif.

À la négation : **sujet + ne + pouvoir / devoir conjugué + pas + infinitif** : {{`Je ne peux pas entrer.`}} / {{`Vous ne devez pas fumer.`}}

| intention    | exemple                     | sens                |
| ------------ | --------------------------- | ------------------- |
| capacité     | {{`Je peux nager.`}}        | I can swim.         |
| permission   | {{`Tu peux entrer.`}}       | You may come in.    |
| obligation   | {{`Vous devez écouter.`}}   | You must listen.    |
| interdiction | {{`Tu ne dois pas fumer.`}} | You must not smoke. |

Pour dire **« you don't have to come »**, utiliser {{`Tu n'es pas obligé de venir.`}} ou {{`Tu n'es pas obligée de venir.`}} Dans une directive, **ne pas devoir faire quelque chose** peut exprimer une interdiction ; **ne pas être obligé de** exprime clairement l'absence d'obligation.

**Avoir le droit de + infinitif** exprime une permission : {{`Nous avons le droit de parler.`}} = We are allowed to speak.

### nous et on à l'oral, piste 4

Dans une conversation familière, on emploie souvent **on** pour dire **nous**. Le verbe se conjugue à la **troisième personne du singulier** : **on peut, on doit, on a**.

| avec nous                            | avec on                         |
| ------------------------------------ | ------------------------------- |
| {{`Nous pouvons entrer en classe.`}} | {{`On peut entrer en classe.`}} |
| {{`Nous avons le droit de partir.`}} | {{`On a le droit de partir.`}}  |
| {{`Nous devons écouter.`}}           | {{`On doit écouter.`}}          |
| {{`Nous ne pouvons pas fumer.`}}     | {{`On ne peut pas fumer.`}}     |

Les deux premières lignes reprennent les exemples imprimés de l'encadré ; les deux suivantes appliquent la même règle aux phrases de l'exercice.

### exercice 1, piste 3 : comprendre les reformulations

| phrase imprimée                      | reformulation pour réviser      |
| ------------------------------------ | ------------------------------- |
| {{`Nous pouvons partir.`}}           | {{`On peut partir.`}}           |
| {{`Nous avons le droit de parler.`}} | {{`On peut parler.`}}           |
| {{`Nous devons écouter.`}}           | {{`On doit écouter.`}}          |
| {{`Nous ne pouvons pas fumer.`}}     | {{`Il est interdit de fumer.`}} |

**Association visible sur la capture : a → Nous avons le droit de parler.** Les lettres des trois autres lignes demandent l'écoute de la **piste 3**. Les reformulations du tableau expliquent le sens ; elles ne constituent pas une transcription de l'audio.

### questions et réponses pour réviser

- {{`Est-ce qu'on peut entrer ?`}} → {{`Oui, on peut entrer.`}}
- {{`Est-ce qu'on doit écouter ?`}} → {{`Oui, on doit écouter.`}}
- {{`Est-ce qu'on peut fumer ici ?`}} → {{`Non, on ne peut pas fumer ici.`}}

**À retenir :** **pouvoir** pour une possibilité ou une permission ; **devoir** pour une obligation ; **ne … pas** autour du verbe conjugué ; un **infinitif** après ce verbe ; **on + singulier** pour parler au nom du groupe.
