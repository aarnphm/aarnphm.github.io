## questions fermées et ouvertes

Révision de [[fr/episode-12#lannonce-corps-et-âme|l'annonce Corps et âme]], manuel p. 91. Les réponses sur les cours ci-dessous reprennent la capture fournie en cours. Les questions sur un anniversaire, une compétition ou un objet sont des modèles à adapter à la situation.

### quelle réponse attend-on ?

| type                 | réponse attendue                                           | exemple                                                                 |
| -------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------- |
| **question fermée**  | **oui** ou **non**, dans les exercices de ce bilan         | {{`Est-ce que vous offrez des cours de yoga ?`}} → {{`Oui.`}}           |
| **question ouverte** | une information : date, heure, lieu, prix, moyen ou raison | {{`Quels cours offrez-vous ?`}} → {{`Nous offrons des cours de yoga.`}} |

Une réponse fermée peut ajouter une explication : {{`Non, un cours d'essai coute dix dollars.`}} Le type de question dépend de la réponse demandée. Une question ouverte peut avoir une réponse courte, par exemple {{`À dix heures.`}}

Dans un autre contexte, une question fermée peut proposer un choix limité : {{`Tu préfères mardi ou jeudi ?`}} Ici, les exemples fermés travaillent les réponses **oui/non**.

### les formes des questions fermées

Les quatre formes suivantes demandent toutes si la personne offre des cours de yoga :

| construction                   | exemple                                          | emploi                            |
| ------------------------------ | ------------------------------------------------ | --------------------------------- |
| **est-ce que + sujet + verbe** | {{`Est-ce que vous offrez des cours de yoga ?`}} | forme générale                    |
| **inversion verbe-pronom**     | {{`Offrez-vous des cours de yoga ?`}}            | forme soignée, avec trait d'union |
| **intonation**                 | {{`Vous offrez des cours de yoga ?`}}            | fréquent à l'oral                 |
| **-tu interrogatif québécois** | {{`Vous offrez-tu des cours de yoga ?`}}         | québécois familier                |

Dans la dernière forme, **vous** est le sujet et **-tu** marque la question. Ce **-tu** reste identique avec d'autres sujets. {{`Avez-vous des cours le mardi soir ?`}} est aussi une question fermée par inversion : {{`Oui, nous avons des cours le mardi soir.`}}

### les formes des questions ouvertes

Pour demander la date de début, on peut dire :

- {{`Quand commence le cours ?`}}
- {{`Quand est-ce que le cours commence ?`}}
- {{`Le cours commence quand ?`}} (oral)

**Est-ce que** peut apparaître dans les deux types. {{`Est-ce qu'on peut s'inscrire par téléphone ?`}} demande une confirmation. {{`Comment est-ce qu'on peut s'inscrire ?`}} demande le moyen de s'inscrire, donc une information.

| mot interrogatif                    | sens en anglais     | information demandée      | exemple                                           |
| ----------------------------------- | ------------------- | ------------------------- | ------------------------------------------------- |
| **quand**                           | when                | date ou moment            | {{`Quand commencent les inscriptions ?`}}         |
| **à quelle heure**                  | at what time        | heure                     | {{`À quelle heure commence le cours ?`}}          |
| **où**                              | where               | lieu                      | {{`Où est le centre de yoga ?`}}                  |
| **comment**                         | how                 | moyen ou manière          | {{`Comment peut-on s'inscrire ?`}}                |
| **combien**                         | how much / how many | prix ou quantité          | {{`Combien coute un cours d'essai ?`}}            |
| **pourquoi**                        | why                 | raison                    | {{`Pourquoi choisis-tu ce cours ?`}}              |
| **qui**                             | who                 | personne                  | {{`Qui donne le cours ?`}}                        |
| **qu'est-ce que**                   | what                | chose ou contenu          | {{`Qu'est-ce que comprend l'offre découverte ?`}} |
| **quel / quelle / quels / quelles** | which / what        | information liée à un nom | {{`Quels moyens de paiement sont acceptés ?`}}    |

**Quel** s'accorde avec le nom : **quel prix** (masculin singulier), **quelle date** (féminin singulier), **quels jours** (masculin pluriel), **quelles dates** (féminin pluriel).

## demander une confirmation ou une information

Chaque paire porte sur le même sujet. La question fermée propose une information à vérifier ; la question ouverte demande cette information.

| sujet       | question fermée                                                | question ouverte                               |
| ----------- | -------------------------------------------------------------- | ---------------------------------------------- |
| début       | {{`Est-ce que les inscriptions commencent le premier juin ?`}} | {{`Quand commencent les inscriptions ?`}}      |
| fin         | {{`Est-ce que les inscriptions finissent le quinze juin ?`}}   | {{`Quand finissent les inscriptions ?`}}       |
| inscription | {{`Est-ce qu'on peut s'inscrire par téléphone ?`}}             | {{`Comment peut-on s'inscrire ?`}}             |
| paiement    | {{`Est-ce que vous acceptez les chèques ?`}}                   | {{`Quels moyens de paiement acceptez-vous ?`}} |
| prix        | {{`Est-ce qu'un cours d'essai coute dix dollars ?`}}           | {{`Combien coute un cours d'essai ?`}}         |
| horaire     | {{`Est-ce qu'il y a un cours le mardi soir ?`}}                | {{`Quels jours ont lieu les cours ?`}}         |

### autres situations à pratiquer

Ces modèles demandent des informations personnelles sans proposer de réponse factuelle sur la personne.

| situation    | question fermée                                                   | question ouverte                                         |
| ------------ | ----------------------------------------------------------------- | -------------------------------------------------------- |
| anniversaire | {{`Est-ce que ton anniversaire est en septembre ?`}}              | {{`C'est quand, ton anniversaire ?`}}                    |
| compétition  | {{`Est-ce que ta compétition à Lanzarote a lieu le samedi ?`}}    | {{`Quel jour a lieu ta compétition à Lanzarote ?`}}      |
| objet        | {{`Est-ce que c'est une montre ?`}}                               | {{`Qu'est-ce que c'est ?`}} / {{`Quel est cet objet ?`}} |
| lire l'heure | {{`Est-ce que tu utilises ton cellulaire pour savoir l'heure ?`}} | {{`Qu'est-ce que tu utilises pour savoir l'heure ?`}}    |

Pour demander le **jour de la semaine** d'un anniversaire : {{`Ton anniversaire tombe quel jour cette année ?`}} Pour demander sa **date** : {{`C'est quand, ton anniversaire ?`}}

## exercice : fermée ou ouverte ?

Classer les huit questions avant de lire les réponses :

1. {{`Est-ce que vous acceptez les chèques ?`}}
2. {{`Comment est-ce que je peux m'inscrire ?`}}
3. {{`À quelle heure commence le cours ?`}}
4. {{`Avez-vous des cours le mardi soir ?`}}
5. {{`Qu'est-ce que comprend l'abonnement ?`}}
6. {{`Le centre offre-tu des cours de yoga ?`}}
7. {{`Quels cours offrez-vous ?`}}
8. {{`Vous offrez des cours de yoga prénatal ?`}}

**Réponses :** 1 fermée ; 2 ouverte ; 3 ouverte ; 4 fermée ; 5 ouverte ; 6 fermée ; 7 ouverte ; 8 fermée.

Pour pratiquer à deux : poser une question fermée, écouter **oui/non**, puis poser une question ouverte sur le même sujet. Exemple : {{`Est-ce que le cours est le mardi ?`}} → {{`Quels jours ont lieu les cours ?`}}
