Raconter au passé, supposer au conditionnel — A2 → B1. Les conjugaisons de base sont dans [[fr/verbs]] ; ici, c'est le choix du temps qui compte.

## Passé composé vs imparfait

| Situation                 | Temps                             | Exemple                                                  |
| ------------------------- | --------------------------------- | -------------------------------------------------------- |
| Événement terminé         | {{`passé composé`}}               | {{`J'ai regardé un film.`}}                              |
| Arrière-plan, description | {{`imparfait`}}                   | {{`Il pleuvait quand nous sommes sortis.`}}              |
| Habitude passée           | {{`imparfait`}}                   | {{`Quand j'étais petit, je jouais dehors.`}} ("used to") |
| Rupture soudaine          | {{`passé composé`}}               | {{`Soudain, la porte s'est ouverte.`}}                   |
| Deux actions simultanées  | {{`imparfait`}} + {{`imparfait`}} | {{`Pendant que tu dormais, je préparais le souper.`}}    |

**Auxiliaires** : DR & MRS VANDERTRAMP + tous les pronominaux → {{`être`}}. Piège : {{`monter`}}, {{`descendre`}}, {{`sortir`}}, {{`passer`}}, {{`retourner`}} prennent {{`avoir`}} avec un objet direct — {{`Elle a monté l'escalier`}} (vs {{`Elle est montée`}}).

**Accord du participe** :

- avec {{`être`}}, hors verbes pronominaux : accord avec le sujet, {{`Ils sont partis.`}}. Pour les pronominaux, la fonction du pronom compte ; voir les exemples ci-dessous.
- avec {{`avoir`}} : accord seulement avec un objet direct **avant** le verbe — {{`Les lettres que j'ai écrites.`}}
- pronominaux : pas d'accord si l'objet direct suit — {{`Elle s'est lavé les mains.`}} (le réfléchi est indirect) ; réciproque indirect pareil — {{`Ils se sont parlé.`}}

## Futur simple

Infinitif + {{`-ai, -as, -a, -ons, -ez, -ont`}} (les verbes en {{`-re`}} perdent le _e_ : {{`prendr-`}}). Radicaux irréguliers : {{`ser-`}}, {{`aur-`}}, {{`ir-`}}, {{`fer-`}}, {{`pourr-`}}, {{`voudr-`}}, {{`viendr-`}}, {{`verr-`}}, {{`enverr-`}}, {{`devr-`}}.

Dans une proposition temporelle qui situe un événement futur, {{`quand`}} / {{`lorsque`}} prend le **futur** là où l'anglais emploie le présent : {{`Quand je serai grand, je serai médecin.`}} Avec {{`si`}} de condition, on emploie le présent : {{`Si j'ai le temps, je viendrai.`}}

## Plus-que-parfait et conditionnel passé

- **Plus-que-parfait** : auxiliaire à l'imparfait + participe — {{`j'avais mangé`}}, {{`j'étais allé(e)`}}. Le « passé du passé ».
- **Conditionnel passé** : auxiliaire au conditionnel + participe — {{`j'aurais fini`}}, {{`je serais parti(e)`}}. Regret et reproche : {{`J'aurais dû étudier.`}}, {{`Tu aurais pu me le dire !`}}

## Les trois schémas en si

| Si…                         | …alors             | Exemple                                   |
| --------------------------- | ------------------ | ----------------------------------------- |
| {{`si`}} + présent          | futur              | {{`Si tu viens, on partira.`}}            |
| {{`si`}} + imparfait        | conditionnel       | {{`Si tu venais, on partirait.`}}         |
| {{`si`}} + plus-que-parfait | conditionnel passé | {{`Si tu étais venu, on serait partis.`}} |

Ces trois schémas concernent les propositions hypothétiques introduites par {{`si`}} de condition : le futur et le conditionnel sont exclus dans cette proposition. Dans une interrogation indirecte, {{`si`}} signifie « est-ce que » ("whether" en anglais) et cette restriction ne s'applique pas : {{`Je me demande s'il viendra.`}} · {{`J'aimerais savoir si vous pourriez venir.`}} {{`Même si`}} de condition prend aussi l'indicatif : {{`Même s'il pleut, on ira.`}} Pour {{`bien que`}} + subjonctif, voir [[fr/subjonctif]].

Conditionnel de politesse : {{`Je voudrais un café.`}}, {{`Voudriez-vous boire quelque chose ?`}}
