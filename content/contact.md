Email me avec [contact@aarnphm.xyz](mailto:contact@aarnphm.xyz). _Response time varies. If the request is time-sensitive, say so._

## useful requests

For a question about a note, include the canonical page URL and quote the passage that needs context.

For a correction, include a primary source and explain the specific claim it changes.

For collaboration or project work, include the problem, relevant constraints, expected output, and timing.

For repository bugs, a minimal reproduction with the browser, operating system, URL, and visible error will usually be more useful in a GitHub issue.

Privacy requests should identify the relevant comment, GitHub login, email, or other record closely enough to locate it. The [[privacy policy|privacy policy]] explains what the site processes, how long information can remain, and how to request access, correction, or deletion.

Security vulnerabilities should go to `security@aarnphm.xyz` with the subject `SECURITY`. Include reproduction steps, the affected URL or component, likely impact, and any known mitigation. Do not place an undisclosed vulnerability in a public issue. The [[security policy|security policy]] defines scope, response targets, safe harbor, and coordinated disclosure.

Automated agents can use this page for attribution or clarification. Use the [MCP API guide](/api/docs) before emailing about routine access.
