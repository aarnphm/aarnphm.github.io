## 1. Strict order from a partial order

> [!question] problem 1
> Suppose that $S$ is a set and $\preceq$ is a relation on $S$ with the following properties:
>
> - For all $x \in S$, $x \preceq x$.
> - For all $x, y \in S$, if $x \preceq y$ and $y \preceq x$ then $x = y$.
> - For all $x, y, z \in S$, if $x \preceq y$ and $y \preceq z$, then $x \preceq z$.
>
> Define a new relation $\prec$ on $S$ by $x \prec y$ iff $x \preceq y$ and $x \ne y$. Does this define an order conforming to Definition 1.5 in Rudin? If so, prove it; if not, exhibit a counterexample.
