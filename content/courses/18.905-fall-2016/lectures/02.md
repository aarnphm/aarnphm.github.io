## the pipeline

The face maps $d_i : \mathrm{Sin}_n(X) \to \mathrm{Sin}_{n-1}(X)$ satisfy the quadratic relations from the homework. A collection of sets $K_n$ ($n \geq 0$) with maps $d_i : K_n \to K_{n-1}$ satisfying those relations is a semi-simplicial set. So

$$
\{\text{spaces}\} \xrightarrow{\ \mathrm{Sin}_*\ } \{\text{semi-simplicial sets}\} \xrightarrow{\ \mathbb{Z}(-)\ } \{\text{semi-simplicial abelian groups}\} \longrightarrow \{\text{chain complexes}\} \xrightarrow{\ H_*\ } \{\text{graded abelian groups}\}.
$$

The third arrow is "form $d = \sum (-1)^i d_i$".

## reversing a 1-simplex

Take $\sigma : \Delta^1 \to X$ and let $\bar\sigma = \sigma \circ \phi$ where $\phi(t, 1-t) = (1-t, t)$ flips the interval. In $S_1(X)$, $\bar\sigma \neq -\sigma$. But $\bar\sigma \equiv -\sigma \bmod B_1(X)$, so if $\sigma$ is a cycle then $\lbrack \bar\sigma \rbrack = -\lbrack \sigma \rbrack$ in $H_1(X)$.

The 2-chain: let $\pi : \Delta^2 \to \Delta^1$ be the affine map with $e_0, e_2 \mapsto e_0$ and $e_1 \mapsto e_1$. Writing $c^n_x$ for the constant $n$-simplex at $x$,

$$
d(\sigma \circ \pi) = \sigma\pi d^0 - \sigma\pi d^1 + \sigma\pi d^2 = \bar\sigma - c^1_{\sigma(0)} + \sigma.
$$

The constant term is an error, killed by the constant 2-simplex: $d\, c^2_{\sigma(0)} = c^1 - c^1 + c^1 = c^1_{\sigma(0)}$. Hence

$$
\sigma + \bar\sigma = d\big(\sigma \circ \pi + c^2_{\sigma(0)}\big).
$$

Language: two cycles differing by a boundary $dc$ are homologous, and $c$ is a homology between them.

## two computations

**Empty space.** $\mathrm{Sin}_n(\emptyset) = \emptyset$, so $S_*(\emptyset) = 0$ and $H_*(\emptyset) = 0$.

**A point.** $\mathrm{Sin}_n(*) = \{c^n_*\}$, so $S_n(*) = \mathbb{Z}$ for $n \geq 0$. Every face of $c^n_*$ is $c^{n-1}_*$, so

$$
d(c^n_*) = \sum_{i=0}^n (-1)^i c^{n-1}_* =
\begin{cases}
c^{n-1}_* & n \text{ even} \\
0 & n \text{ odd.}
\end{cases}
$$

The complex is $0 \leftarrow \mathbb{Z} \xleftarrow{0} \mathbb{Z} \xleftarrow{1} \mathbb{Z} \xleftarrow{0} \mathbb{Z} \xleftarrow{1} \cdots$. Cycles and boundaries agree except in degree zero, where $B_0 = 0$ and $Z_0 = \mathbb{Z}$. So $H_0(*) = \mathbb{Z}$ and $H_i(*) = 0$ for $i \neq 0$.

## induced maps

A continuous $f : X \to Y$ gives $f_* : \mathrm{Sin}_n(X) \to \mathrm{Sin}_n(Y)$, $\sigma \mapsto f \circ \sigma$. It commutes with faces: $d_i f_* \sigma = f \circ \sigma \circ d^i = f_* d_i \sigma$. A diagram is commutative when all composites with the same source and target agree. Passing to free abelian groups keeps the square commutative.

A chain map $f : C_* \to D_*$ is a family $f_n : C_n \to D_n$ with $d_D f_n = f_{n-1} d_C$. So $f_* : S_*(X) \to S_*(Y)$ is a chain map.

**A chain map induces $f_* : H_n(C) \to H_n(D)$.** The first diagram chase of the course:

- cycles go to cycles: if $d_C c = 0$ then $d_D f_n(c) = f_{n-1} d_C c = 0$;
- boundaries go to boundaries: if $c = d_C c'$ then $f_n(c) = f_n d_C c' = d_D f_{n+1}(c')$.

The two maps descend to the quotient.
